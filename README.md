# 🚀 Nimbo

Современное автономное десктопное приложение для Windows на базе **Electron + React + yt-dlp** для быстрой и удобной загрузки видео (MP4) и музыки (MP3) с YouTube.

---

## 🎨 Особенности

- 📹 **Выбор формата**: MP4 (до 4K UHD) или MP3 (до 320 kbps).
- 🖼 **Превью ролика**: Автоматическая подгрузка обложки, автора и хронометража при вставке ссылки.
- ⚡ **Высокая скорость**: Скачивание с отслеживанием точного процента загрузки в реальном времени.
- 📂 **Удобное хранение**: Все медиафайлы сохраняются в папку `Загрузки / YouTube_Downloads`.
- 🛡 **Обход блокировок**: Встроенная система эмуляции клиентов YouTube против ошибок `HTTP 403 Forbidden`.

---

## 📦 Быстрый запуск для разработчиков

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/YOUR_USERNAME/voytees-downloader.git
   cd voytees-downloader
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите в режиме разработки (Desktop Electron App):
   ```bash
   npm run electron:dev
   ```

---

## 🛠 Сборка .exe файла для релиза на GitHub

Чтобы собрать готовый установочный файл `.exe` для пользователей:

```bash
npm run electron:build
```

Исполняемый файл появится в папке `dist/` или `dist_electron/`.

---

## 📋 Системные требования
- **OS**: Windows 10 / 11
- **Зависимости**: `yt-dlp` и `ffmpeg` (устанавливаются автоматически через `winget` или системные пакетировщики).
